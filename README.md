# Teste Front-End Júnior

Projeto desenvolvido para o teste técnico de Front-End da Econverse, seguindo o layout disponibilizado no Figma.

## Tecnologias utilizadas

- React + TypeScript
- Styled Components
- Sass
- JSON Server
- Vite
- Vitest

## Como rodar o projeto

É necessário ter o Node.js instalado.

**1. Instalar as dependências:**

```bash
npm install
```

**2. Iniciar o projeto:**

```bash
npm run dev
```

O front-end estará disponível em http://localhost:5173 e a API em http://localhost:3001.

## Testes

Para executar os testes:

```bash
npm test
```

## Funcionalidades

- Página inicial seguindo o layout do Figma.
- Listagem de produtos consumindo uma API mock.
- Modal com detalhes dos produtos.
- Carrossel de produtos.
- Layout responsivo para desktop e celular.

## Sobre o projeto

Os produtos são carregados pelo JSON Server, utilizando os dados do arquivo `db.json`. A estilização foi feita com Styled Components e Sass, sem utilizar bibliotecas de interface."# Teste_Econverse_Front_End"
